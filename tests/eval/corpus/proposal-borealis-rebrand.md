# Borealis Museums Consortium — Brand & Web Refresh Proposal

DFFRNT proposes a brand and web refresh for the Borealis Museums Consortium's four member museums.

**Budget:** $85,000 fixed price. **Duration:** 8 weeks.

## Deliverables

- A flexible logo system that adapts to each member museum
- A brand style guide covering typography, colour, and voice
- A web component library implemented in the consortium's CMS
- Three responsive page templates: exhibition, visit planning, donation

## Optional add-on

A WCAG accessibility audit of the existing web estate can be added for $12,000.

## Assumptions

Content migration is handled by the consortium's web team. DFFRNT delivers source files in Figma.
